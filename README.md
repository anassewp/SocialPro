# SocialPro

SocialPro هو نظام تسويق متكامل مكتوب بلغة بايثون يركز في نسخته الأولى على تيليجرام مع تصميم يمكّن من التوسع مستقبلًا ليشمل منصات مثل فيسبوك وواتساب وإنستغرام. يجمع النظام بين إدارة الحسابات، وإرسال الرسائل الفردية والجماعية، وإدارة المجموعات، واستخراج البيانات التحليلية، بالإضافة إلى نظام اشتراك شهري وسنوي مع دعم كامل للغتين العربية والإنجليزية.

## المميزات الرئيسية
- **إدارة الحسابات:** إضافة حسابات تيليجرام باستخدام رقم الهاتف أو معرف المستخدم.
- **لوحة معلومات تفاعلية:** عرض فوري لإحصائيات الحملات والتقارير المباشرة والرسائل المترجمة.
- **أدوات التسويق:** إرسال رسائل فردية وجماعية، وإضافة أعضاء إلى المجموعات، وتسجيل جميع الأنشطة.
- **التحليلات والتقارير:** إنشاء تقارير أداء تلقائية مع مؤشرات التفاعل ونسب المشاركة.
- **نظام الاشتراك:** خطط شهرية وسنوية مع مزايا إضافية للمشتركين السنويين.
- **دعم ثنائي اللغة:** جميع الرسائل الأساسية متوفرة بالعربية والإنجليزية مع سهولة التبديل بينهما.

## البدء السريع
1. تثبيت الاعتمادات:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
2. تشغيل الخادم:
   ```bash
   uvicorn app:app --reload
   ```
3. زيارة واجهة التوثيق:
   افتح `http://127.0.0.1:8000/docs` للاطلاع على واجهة Swagger التفاعلية.

## بنية النظام
- `app.py`: تطبيق FastAPI الذي يوفّر واجهة برمجية أمامية قابلة للتوسع.
- `socialpro/system.py`: الواجهة الرئيسية التي تنسّق الخدمات والمستودعات.
- `socialpro/services/`: طبقة الخدمات التي تحتوي على المنطق التجاري مع تعليقات عربية توضيحية لكل دالة.
- `socialpro/repositories.py`: تخزين بيانات داخل الذاكرة يمكن استبداله لاحقًا بقاعدة بيانات.
- `socialpro/localization.py`: رسائل مترجمة قابلة للتوسعة للغات إضافية.
- `docs/Documentation.md`: دليل شامل لشرح الوظائف وطريقة التخصيص والتكامل مع الأنظمة الخارجية.

## التوسع المستقبلي
تم تصميم SocialPro بصورة معيارية تسمح بإضافة منصات جديدة بسهولة عن طريق إنشاء خدمات ومستودعات متخصصة وتحديث واجهة البرمجة الأمامية. كما يمكن دمج النظام مع أدوات تحليلات أو CRM خارجية وإضافة خصائص مثل الرسائل الذكية والتحليلات المعتمدة على التعلم الآلي.

## الترخيص
يتم توفير الشيفرة كمثال مرجعي ويمكن تعديلها لتناسب احتياجات المشاريع التجارية المختلفة.
